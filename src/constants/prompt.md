-   You are a Nextjs developer. Create a navbar. When user hovers over nav items its submenu should transition from height 0 to auto. You can use grid-template-rows css feature to accomplish this. The submenu menu is in another component which renders conditionally depending upon mouse position on navbar items. On mouse entering a navbar item it will trigger a function which sets a state value to that item id. This is then passed as props to submenu component which conditionally renders that item submenu. When a submenu is displayed user should be able to access its content. The submenu should be closed only when user moves to another menu items or outside menu container. Also please note that some item may not have submenu. Submenu is position fixed and takes the entire viewport width and each submenu has different layouts so you can't use map function to display contents it has to be conditionally rendered.
